Along with the new version of Pyto, I am releasing PytoRuntime. It is a package containing all components for Python to run on Apple sandboxed environments (Interpreter, Packages, Libraries, Patches) and a high level API for integration with the frontend.

New app features

  • New native Mac app
  • New design adapted for Liquid Glass
  • Removed left sidebar and added an inspector
  • Added a tab bar in the code editor
  • Re-designed the tree explorer and re-wrote with tree-sitter
  • Text settings can now be applied to files individually
  • Added editorconfig support
  • App settings and themes are now stored as JSON
  • Added a Jump To action in the code editor
  • The terminal below the editor now supports multiple sessions
  • New virtual environment manager
  • Git integration in the file browser

Tooling changes

  • Updated packages and Python to 3.14
  • Various improvements to shell
  • Added a WebAssembly runtime supporting WASIX syscalls
  • Added 'pytorch' and 'llama-cpp' and other packages
  • Added 'curses', 'termios' and 'readline' modules
  • Added a 'git' command based on libgit2
  • Added 'ninja' and 'pkgconf'
